# ESTRUTURA — Portfólio de Isaac Costantin

## Visão geral

O **ESTRUTURA** é um portfólio pessoal desenvolvido para apresentar meus projetos, minhas habilidades e minha evolução como estudante de Desenvolvimento de Sistemas na ETEC.

O projeto utiliza uma identidade visual inspirada em estúdios criativos e no desenho técnico, combinando um fundo escuro, cores contrastantes, elementos gráficos e animações para criar uma experiência visual própria.

O site apresenta projetos desenvolvidos individualmente e em equipe, uma seção sobre o autor e canais de contato.

## Acesso ao projeto

**Aplicação online:** https://isaac-costantinportfolio.vercel.app/

**Repositório:** https://github.com/IsaacCostantin/Isaac-Costantin

## Tecnologias e bibliotecas

- **HTML5:** estruturação e organização do conteúdo.
- **CSS3:** estilização, layout responsivo, animações e identidade visual.
- **Bootstrap 5.3.3:** biblioteca utilizada para auxiliar na construção do layout responsivo.
- **Google Fonts:** fontes Space Grotesk e IBM Plex Mono.
- **SVG:** criação do fundo gráfico em formato de malha.
- **Vercel:** hospedagem e publicação da aplicação.
- **GitHub:** armazenamento e versionamento do código-fonte.

## Estrutura de arquivos

```text
Isaac-Costantin/
├── README.md
├── index.html
└── style.css
```

- `index.html`: contém a estrutura das seções, os textos, a navegação e os links do portfólio.
- `style.css`: reúne os estilos visuais, as cores, a tipografia, as animações e as regras de responsividade.
- `README.md`: apresenta a documentação do projeto.

## Sobre o Autor

Meu nome é Isaac Costantin e sou estudante de Desenvolvimento de Sistemas na ETEC. Tenho interesse em programação, desenvolvimento web e criação de projetos que combinem funcionalidade e identidade visual.

Este portfólio faz parte da minha jornada de aprendizado, reunindo trabalhos desenvolvidos durante meus estudos e servindo como espaço para experimentar ideias e aprimorar minhas habilidades.
